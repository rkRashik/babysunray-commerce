# Offline sheets for an outage

**Status:** Draft — Founder Review. **Purpose:** Blank sheets to print and keep for when the system is unavailable (requirement K-7), with the procedure in [runbook.md](runbook.md), section 9.

These sheets are a fallback record only. They are not a backup and cannot restore the system. Keep filled sheets private (they hold customer details) and destroy them once everything is entered.

## Order sheet

Temporary references look like `OFF-<MMDD>-<number>`. Never write a real order number here.
